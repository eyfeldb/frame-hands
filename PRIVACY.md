# Data handling

The tracker processes camera data on the headset. Diagnostic tools can also record camera images, poses, or rendered scenes when started explicitly. Check their arguments and output paths before using them, and keep recording off by default during installation.

This repository excludes recordings, joint and gaze traces, personal hand profiles, device settings, installation reports, and credentials. Keep that data in ignored local folders.

Before sharing logs or captures in a public issue, remove personal imagery, local paths, device identifiers, and paired-host details. Use a small synthetic example when it can reproduce the problem.
