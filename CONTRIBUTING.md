# Contributing

Run the source checker and driver tests in the [README](README.md) before submitting a change. Keep changes focused so their effects on tracking, transport, or rendering are easy to measure. When testing on a headset, keep a working version you can restore.

For hardware results, include the date, OS and runtime versions, source revision, build options, and whether the app runs on the headset or streams from a PC. Describe what you measured and what you saw; keep possible explanations separate from results.

Leave recordings, pose traces, personal profiles, device settings, compiled drivers, and downloaded dependencies out of pull requests. Document any extra dependencies your tests need.
